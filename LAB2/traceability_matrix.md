## 4. Матриця трасування (Traceability Matrix)

| ID вимоги (EARS) | Опис вимоги | Пов'язані Use Cases (ID) |
| :--- | :--- | :--- |
| **REQ-1** | Дозвіл на перегляд каталогу книг із зазначенням ціни та авторів | UC1 |
| **REQ-2** | Зміна статусу Замовлення на "Оплачено" після успішної транзакції | UC3, UC4 |
| **REQ-3** | Блокування можливості зміни складу кошика під час обробки платежу | UC2, UC3, UC4 |
| **REQ-4** | Скасування оплати та показ повідомлення про помилку при відхиленні платежу | UC4, UC_Error |
| **REQ-5** | Надсилання щотижневої маркетингової розсилки за згодою клієнта | - |
| **REQ-6** | Автоматичний перерахунок загальної суми замовлення при додаванні позиції до кошика | UC2, UC_Calc |

**Примітка:** Вимога **REQ-5** (про маркетингову розсилку) навмисно не покрита жодним Use Case, оскільки цей функціонал виходить за межі поточного MVP, який фокусується виключно на процесі покупки та чекауту.
